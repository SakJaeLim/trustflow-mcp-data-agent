# AI use disclosure

## 제품 런타임

- 유형 1 외부 모델 그대로 활용
- gemma4:e2b: 미등록 자연어 표현의 구조화 계획 초안과 evidence-bound 답변
- nomic-embed-text: 40개 공식 Markdown 문서와 질의의 768차원 임베딩
- 추가 학습·파인튜닝·파생 가중치: 없음

## 개발 보조

OpenAI Codex를 아키텍처 검토, 코드 초안, 테스트 작성·실행, UI 검증, 문서 작성 보조에 사용했습니다. 생성 결과는 로컬 타입 검사, 자동 테스트, PostgreSQL/pgvector 스모크, Playwright 화면 검증으로 확인했으며, 최종 제출 책임은 참가자에게 있습니다.

개발 보조 AI 적용 비율은 코드 줄 수가 아니라 개발 공정 기준의 자체 산정치입니다.

- 적용 범위 또는 비율: 약 80%. 아키텍처 검토, 코드·테스트 초안, UI 구현·검증, 문서·제출물 초안과 반복 수정에 활용
- 산정 방식: 설계, 구현, 시험, UI·시연, 문서화의 5개 공정 중 4개 공정에 AI가 실질적으로 참여한 것으로 보아 80%로 산정
- 사용 기간/주요 작업: 최종 구현·검증 단계인 2026-08-23~2026-08-24, PolicyGraph 구현·보안 회귀·평가·보고서·영상 제작
- 사람이 직접 검토·수정한 범위: 과제 방향과 차별화 결정, 공개 범위 승인, 사용자 정보 확인, 로컬 실행 결과 검토, 최종 제출 승인 전체

이 비율은 AI가 작성한 코드 줄 수나 저작권 귀속 비율을 뜻하지 않으며, 개발 과정에서 AI 보조가 개입한 공정의 범위를 투명하게 설명하기 위한 자체 추정치입니다.
