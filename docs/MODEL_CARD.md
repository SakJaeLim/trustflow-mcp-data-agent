## 적용 방식

- 공식 30문항은 재현 가능한 결정적 계획을 사용합니다.
- 템플릿에 없는 표현만 Gemma 4가 JSON Schema에 맞춘 단일 도구 계획을 초안합니다.
- 모델은 도구를 직접 실행하지 못하며 모든 계획은 PlanGate를 통과합니다.
- 답변 생성 시 최대 10개 근거의 ID·출처·payload만 전달합니다.
- temperature=0, num_ctx=4096, num_predict=512, thinking 비활성으로 제한합니다.
- 잘못된 evidenceId 또는 근거에 없는 식별자·수치를 포함하면 결정적 근거 포매터로 대체합니다.
- 로컬 모델 호출이 timeout·HTTP 오류·메모리 부족으로 실패하면 알려진 문서 질의는 제한된 검색 계획으로 전환하고, 그 밖의 확인되지 않은 계획은 실행하지 않습니다.
