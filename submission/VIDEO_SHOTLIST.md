# 3분 시연영상 shot list

> 제출 영상과 최종 코드에는 자동 테스트 37/37을 동일하게 반영한다.

## 녹화 전 준비

- [ ] 해상도 1920×1080, 브라우저 100%, 알림·개인정보·북마크 숨김
- [ ] `npm run dev:web` 실행 후 http://127.0.0.1:4173 상태 확인
- [ ] `.env`, 비밀번호, 승인 영수증, 로컬 사용자 경로는 촬영하지 않음
- [ ] SQL·Vector·Graph 질문을 한 번씩 예행 실행해 화면 위치 고정
- [ ] 결과보고서 수치와 `artifacts/evaluation/` 수치 일치 확인
- [ ] 3분 타이머와 대본을 보조 화면에 준비

## 장면 구성

| 구간 | 화면 | 필수 증거 | 최대 |
|---:|---|---|---:|
| 1 | 첫 화면 | 30 questions, 3 MCP tools, 서버 역할 | 18초 |
| 2 | NL2SQL | REPAIR, AST 계획, SQL_LIMIT_ADDED, 표 근거 | 27초 |
| 3 | Vector | DOC-011, verified answer, passage evidence | 27초 |
| 4 | Graph | graph.traverse, USES 경로 | 23초 |
| 5 | 공격 | DENY, DENIED, evidence 0, 정책 코드 | 35초 |
| 6 | LLM·감사 | Gemma 평가와 signed checkpoint valid | 27초 |
| 7 | 결과 | 30/30, 8/8, Hit@1, 37/37 | 21초 |

## 편집 원칙

- 장면 전환은 단순 cut을 사용하고 과도한 애니메이션을 넣지 않는다.
- 클릭 직후 결과가 보이도록 불필요한 대기 구간만 제거한다. 정책 결과 자체는 가속하지 않는다.
- 핵심 값은 2~3초 확대하되 전체 UI 맥락을 한 번 이상 보여준다.
- 배경음은 음성을 방해하지 않게 하거나 생략한다.
- 영상 마지막에 공개 저장소 URL과 `Apache-2.0`을 2초 표시한다.
- Gemma 4 CPU 라이브 생성은 20~30초가 걸리므로 평가 결과를 촬영하고 실제 원자료 경로를 자막으로 명시한다.

- [ ] 1080p 처리 완료 확인

- [ ] 결과보고서와 영상의 버전·수치·프로젝트명이 일치하는지 확인
